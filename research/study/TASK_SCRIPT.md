# Participant task script

You will resume interrupted AI coding sessions. All projects are **synthetic**. Do not use employer repositories or paste secrets.

There are two conditions. In each condition you will complete three tasks. Follow the facilitator’s instruction for which tool/method to use.

---

## Shared scenario background

You are mid-way through fixing a small TypeScript utility library. An earlier AI coding session already:

- identified a CSV escaping bug,
- started adding unit tests,
- discussed (but did not finish) extracting a `serializeRow` helper.

Your job is to **continue** that work after an interruption, using only the recovery method allowed in the current condition.

---

## Task 1 — Resume after terminal close

The terminal/session was closed. Recover context and make the next correct code edit toward finishing `serializeRow` tests.

**Success:** You produce or accept an edit that adds/fixes a failing escaping test or implements the helper consistent with the prior session goal.

**Cap:** 12 minutes.

---

## Task 2 — Resume after delay

Imagine one day passed. Using the allowed recovery method, re-establish what was decided about escaping commas/quotes, then continue.

**Success:** You correctly state or apply the escaping decision from the prior session without inventing a conflicting rule, and take one productive next step.

**Cap:** 12 minutes.

---

## Task 3 — Transfer / cross-tool or orphan recovery

Facilitator assigns one of:

- **3A Machine transfer:** import/recover the session on a second workspace and continue once.
- **3B Cross-tool:** continue the same task in a different AI coding tool using the allowed method.
- **3C Orphan recovery:** locate and resume a session missing from the provider’s usual history index.

**Success:** You identify the correct prior objective and take one correct continuation action without opening unrelated sessions as the primary path.

**Cap:** 12 minutes.

---

## During tasks

- Think aloud if comfortable.
- You may search transcripts if the condition allows.
- Ask clarifying process questions; the facilitator will not give solution hints.
